Политика конфиденциальности — Prompt Forge

Кто мы. Prompt Forge — внутренний инструмент для сотрудников, который разрабатывает и поддерживает компания Prompt Forge. Расширение недоступно посторонним: оно распространяется приватно и работает только с персональным ключом сотрудника.

Что собирает расширение

  • Токен ClickUp — вводится сотрудником, хранится только в его браузере (chrome.storage.local) и отправляется исключительно на серверы ClickUp (clickup.com) для чтения задач.
  • Персональный ключ команды — хранится в браузере, отправляется только на сервер компании.
  • Содержимое задач ClickUp (текст, названия вложений) и вложения (картинки, видео из описания задачи) — читаются, когда сотрудник нажимает «Сгенерировать», и передаются на сервер компании для формирования промптов.
  • Файлы, которые сотрудник прикрепляет сам — «Свой реф» на карточке креатива: файл с диска, скриншот из буфера или файл по ссылке. Обрабатываются так же, как вложения задачи.
  • Личный ключ Gemini — необязательное поле в настройках. Хранится в браузере и передаётся на сервер компании в заголовке запроса, чтобы генерация шла под ним вместо общего ключа команды.

Куда уходят данные

  • На сервер компании (Supabase, проект компании): сохраняются текст задачи, отправленные модели промпты и результаты генераций, имя и почта сотрудника, время и объём запросов (для лимитов и статистики). Сами файлы вложений в базу не пишутся — только их имена, типы и размеры.
  • В Google Gemini API: текст задачи, вложения и внутренние правила компании — для генерации. Вложения хранятся в Gemini Files API не дольше 48 часов. Условия обработки Google: ai.google.dev/terms.
  • На ClickUp: только запросы чтения задачи вашим токеном.
  • На Google Drive и Pinterest: только скачивание файлов по ссылкам, которые есть в описании задачи, с правами вашего браузера.

Никакие данные не продаются и не передаются третьим лицам помимо перечисленных сервисов.

Что не собирается

История браузера, содержимое других сайтов, файлы с диска помимо тех, что сотрудник прикрепил сам, данные вкладок, кроме адреса открытой задачи ClickUp.

Хранение и удаление

Данные в браузере удаляются кнопкой «Сбросить локальные настройки» или удалением расширения. Данные на сервере компании удаляются по запросу администратору: admin@company.com.
